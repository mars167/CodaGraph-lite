## 为什么 (Why)

当前的着陆页缺乏能够吸引开发者受众的一致且现代的深色主题。熟悉 GitHub 生态系统的用户更喜欢其专业、高对比度的深色美学。采用这种风格将提升 CodaGraph Lite 的视觉吸引力和感知质量。

## 变更内容 (What Changes)

- **配色方案**: 采用 GitHub 的深色主题颜色（例如：`#0d1117` 背景，`#161b22` 卡片，`#21262d` 边框）。
- **排版**: 更新字体栈以匹配 GitHub 的 system-ui 偏好。
- **组件**:
  - 重构卡片，使用微妙的边框和纯色背景代替阴影和渐变。
  - 更新按钮，使用 GitHub 的主要（绿色）和次要（灰色）按钮样式。
  - 将 Hero 部分的渐变替换为干净的深色背景。
- **布局**: 保持现有的内容结构，但优化间距和对齐方式以匹配 GitHub 的密度。

## 能力 (Capabilities)

### 新增能力
- `landing-page-theme`: 基于 GitHub 的深色主题定义着陆页的视觉设计系统和组件样式。
